MY PERSONAL PORTFOLIO — QUICK START

1. Extract the ZIP file to a folder on your computer.
2. Open the folder.
3. Double-click index.html to preview the website in your browser.
4. Edit index.html in Notepad or Visual Studio Code.
5. Replace "Your Name", degree, branch, location, email, and social links with your details.
6. Save the file and refresh your browser.

PUBLISH ONLINE FOR FREE USING GITHUB PAGES
1. Create or sign in to a GitHub account: https://github.com/
2. Create a new public repository named username.github.io (replace username with your GitHub username).
3. Upload index.html, style.css, and script.js from this folder to the repository root.
4. Open repository Settings > Pages. If needed, choose Deploy from a branch, select main and / (root), then Save.
5. Wait a few minutes and open https://username.github.io/ (replace username with your GitHub username).

IMPORTANT
- The URL above is an example until you publish the site.
- Update the sample content and contact links before sharing.
- Google Fonts requires an internet connection; the website still works with fallback fonts offline.
